# Superpower Quiz Clone (Angular)
##Formação Angular Developer

---

## 📌 Sobre o desafio
Este projeto foi modificado com base no desafio de projeto "Criando um clone do BuzzFeed com Angular" do bootcamp da **DIO** (Digital Innovation One). 

A aplicação consiste em um `Quiz` ( Um **quiz** é uma forma de jogo ou teste que consiste em perguntas e respostas, geralmente organizadas em formato de competição ) interativo onde o usuário responde a perguntas estratégicas e, ao final, descobre o seu **Superpoder Secreto** com base nas suas escolhas. O projeto passou por uma reformulação completa de conteúdo e identidade visual **(CSS)** para entregar uma experiência moderna, limpa e responsiva.

## 🛠️ Tecnologias utilizadas
- `HTML5` — Estruturação semântica.
- `CSS3` — Estilização avançada.
- `TypeScript` — Lógica e gerenciamento de estados do quiz.

- `Git & GitHub` — Controle de versão e versionamento.
- `JSON` — (JavaScript Object Notation) é um formato leve de texto estruturado baseado em pares de chave e valor.
## Sobre Json: 
- (JavaScript Object Notation) é um formato leve de texto estruturado baseado em pares de chave e valor.

Ele serve para armazenar, organizar e transferir dados de forma padronizada entre diferentes sistemas ou partes do código.

No projeto, ele atua como a base de dados estática que alimenta a aplicação com as perguntas, alternativas e regras de pontuação.

Facilita a leitura e manipulação das informações em tempo de execução de forma nativa e eficiente pelo JavaScript.

## ✨ Melhorias e Customizações Realizadas
* **Mudança de Tema:** Migração completa da temática original para o tema exclusivo **"Superpoder Secreto"** (com novas perguntas, opções e mapeamento de resultados personalizados no arquivo `JSON`).
* **Identidade Visual Profissional:** Substituição da paleta antiga por um design minimalista em **escala de preto e cinza** (tons de carvão, cinzas refinados e transições suaves de hover nos botões).
* **Responsividade e Layout:** Ajustes finos de estrutura e espaçamento para garantir uma navegação perfeita e fluida em diferentes tamanhos de tela.
